# AlicornSpeak — คู่มือติดตั้งแบบเชื่อมฐานข้อมูล PostgreSQL

โปรเจกต์นี้แบ่งเป็น 2 ส่วน:
- **หน้าเว็บ (frontend)** — ไฟล์ `index.html`, `style.css`, `app.js`, `manifest.json`, ไอคอน
- **เซิร์ฟเวอร์ (backend)** — โฟลเดอร์ `server/` เชื่อมต่อกับ PostgreSQL ผ่าน REST API

ทั้งสองส่วนต้อง **รันพร้อมกัน** บนเครื่องเดียวกับที่มี PostgreSQL อยู่ (localhost)

---

## ขั้นตอนที่ 1 — สร้างฐานข้อมูลใน pgAdmin

1. เปิด pgAdmin แล้วสร้างฐานข้อมูลใหม่ชื่อ `alicornspeak` (คลิกขวาที่ Databases → Create → Database)
2. คลิกขวาที่ฐานข้อมูล `alicornspeak` → เลือก **Query Tool**
3. เปิดไฟล์ `server/schema.sql` ที่ให้มา คัดลอกทั้งหมดวางในหน้า Query Tool แล้วกด **Execute (F5)**
4. ตรวจสอบว่ามี 3 ตารางเกิดขึ้น: `users`, `srs_progress`, `daily_stats`

## ขั้นตอนที่ 2 — ติดตั้งและรัน Backend

ต้องมี [Node.js](https://nodejs.org) ติดตั้งไว้ในเครื่องก่อน (เวอร์ชัน 18 ขึ้นไป)

```bash
cd server
npm install
cp .env.example .env
```

แก้ไขไฟล์ `.env` ที่สร้างขึ้น ใส่รหัสผ่าน PostgreSQL ของคุณให้ตรง เช่น:
```
DATABASE_URL=postgresql://postgres:รหัสผ่านของคุณ@localhost:5432/alicornspeak
PORT=3000
```

จากนั้นรันเซิร์ฟเวอร์:
```bash
npm start
```

ถ้าสำเร็จจะเห็นข้อความ `✅ AlicornSpeak API กำลังทำงานที่ http://localhost:3000` — **ต้องเปิดหน้าต่างนี้ค้างไว้ตลอดเวลาที่ใช้งานแอป**

ทดสอบว่าเชื่อมฐานข้อมูลติดหรือไม่ โดยเปิดเบราว์เซอร์ไปที่ `http://localhost:3000/api/health` ควรเห็น `{"ok":true}`

## ขั้นตอนที่ 3 — เปิดหน้าเว็บ

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (ดับเบิลคลิกได้เลย หรือใช้ Live Server ใน VS Code)
สมัครสมาชิกและใช้งานได้ตามปกติ — ข้อมูลทุกอย่าง (บัญชี, ความก้าวหน้า, สถิติ) จะถูกบันทึกลง PostgreSQL จริง ตรวจดูได้ผ่าน pgAdmin โดยคลิกที่ตาราง `users`, `srs_progress`, `daily_stats` แล้วเลือก **View/Edit Data → All Rows**

---

## ⚠️ ข้อจำกัดสำคัญ: ใช้ได้เฉพาะบนเครื่องนี้

เพราะฐานข้อมูล PostgreSQL อยู่บน `localhost` (เครื่องของคุณเอง) **คนอื่นจะเปิดใช้งานแบบเชื่อมฐานข้อมูลจริงจากเครื่องอื่นไม่ได้** — ใช้ได้เฉพาะตอนที่นั่งอยู่หน้าเครื่องนี้เท่านั้น

**ถ้าต้องการส่งให้อาจารย์ดูจากเครื่องอื่น** มีทางเลือก 2 แบบ:

1. **ส่งเดโม่ธรรมดา (ไม่ต้องมีฐานข้อมูลจริง)** — ใช้ลิงก์ที่เผยแพร่ไว้ก่อนหน้านี้ (เก็บข้อมูลแบบ localStorage ในเบราว์เซอร์อาจารย์เอง) เหมาะสำหรับให้ดู UI/ฟีเจอร์เฉยๆ
2. **ย้ายขึ้น Cloud จริง** — ถ้าต้องการให้ใช้งานจากที่ไหนก็ได้พร้อมฐานข้อมูลจริง ต้อง:
   - ย้ายฐานข้อมูลไปยังบริการ Postgres บนคลาวด์ เช่น [Supabase](https://supabase.com) หรือ [Neon](https://neon.tech) (มีแผนฟรี)
   - นำโค้ดใน `server/` ไป deploy บนบริการอย่าง [Render](https://render.com) หรือ [Railway](https://railway.app)
   - แก้ค่า `API_BASE` ในไฟล์ `app.js` ให้ชี้ไปยัง URL ของ backend ที่ deploy แล้ว
   - อัปโหลดไฟล์ frontend ขึ้น GitHub Pages ตามที่เคยแนะนำไว้

   บอกได้เลยถ้าต้องการให้ช่วยตั้งค่าขั้นตอนนี้ต่อ
